# 主机级任务窗口能耗：host_task_window_v1

按用户要求，MAHDRL、所有消融（包括 TL_2）、ERTF-H-FIFS、MARL、PD3QN、IRWS 与 IRWS Paper 统一使用每台主机自身的任务窗口。公共基准/缓存环境也使用同一积分函数，但 FCFS/FIFS 调度和缓存中的参考完成时间不变。

对主机 h，S_h 是该主机全部实际任务中最早的开始时刻，F_h 是最晚的结束时刻；能耗为在 [S_h,F_h] 上对主机功率积分，并对所有使用过的主机求和。任务占用包含输入传输、计算与输出传输。负载仍按该主机当前占用 VM 的计算能力之和除以主机总计算能力计算，功耗曲线不变。

边界规则：

- 整回合没有任何任务的主机，全部时间不计能耗。
- 使用过的主机，只去掉它自身首个任务之前、最后一个任务之后的时间。
- 首尾之间的内部空闲间隔仍计空闲功率，即使当时该主机上所有 VM 都空闲。
- 不按每条 VM 行分别裁剪。某 VM 从未使用也不会让主机的基础功耗减少；只要同一主机的其他 VM 形成了有效任务窗口，该主机就在窗口内计能耗。
- 首尾之外不计只是这次采用的计量假设，未增加开关机、休眠或启动开销模型。

例如，H0 上 VM0 执行 [10,20] 秒的任务，VM1 执行 [30,40] 秒的任务：H0 的计量窗口是 [10,40]，中间 [20,30] 计空闲功率；10 秒前、40 秒后不计。若 H1 整回合没任务，H1 能耗为零。不能把两个 VM 分别裁成 [10,20] 与 [30,40] 后忽略中间十秒。

公共积分函数只让正负载、正持续时间的实际任务定义边界；历史零负载记录被忽略。显式 start_time/end_time 是裁剪范围，不再强制所有主机共享窗口。保留显式 accounting="full_cluster_v1" 仅用于历史图表对照；正式环境与评测均使用默认 host_task_window_v1。

训练奖励也使用主机任务窗口。MAHDRL、MARL 的时间推进结算只确认已经覆盖的任务窗口；主机再次接到任务时，之前暂未计入的间隔成为内部空闲，随后补入奖励。PD3QN、IRWS 的分配增量积分会在扩展已有主机窗口时计入新增内部空闲。所有版本都保留各算法原有的全局/所选主机奖励范围与延迟权重，不重新定义任务信用分配。

新模型目录、评测目录、运行元数据和 Checkpoint 归一化元数据均带有能耗口径标识。正式加载拒绝缺少/不匹配该标识的旧模型，避免把旧奖励训练的权重当作新结果。原有全系统窗口的模型、日志和 outputs/small_gantt 历史图表保留；本次未重训正式 600 回合实验。缓存无需因为本次能耗修改而重建，共享状态参考尺度亦不因积分窗口单独重新校准。

验证包括：未用主机为零、主机首尾裁剪、内部空闲保留、两个 VM 共享主机窗口、零负载标记不扩展边界、增量积分与记录复算一致、各环境的单任务及两次到达间隔的能耗奖励守恒。
