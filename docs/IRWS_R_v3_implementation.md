# IRWS 跨区间批量加速实现

日期：2026-10-26。当前入口仍为 `algorithms/irws_r/train.py` 和 `evaluate.py`，内部模型标识为 `irws_r_v3_rollout`。原 `irws_r_v2_batch` 已保存到 `algorithms/irws_r_v2/`，入口改为该目录，使用原检查点与输出目录。原始简化版、irws_paper、irws_restored、逐样本版及公共仿真函数均保留。

## 配置与训练边界

- 默认 `--rollout-size 64 --slot-duration 5 --precision float32`。学习率、gamma=.2、clip=.2、batch上限64、网络宽度、轨迹截断16、四组Adam、固定Q头及奖励融合公式不变。
- 调度周期和训练窗口是两个时钟。网络在收集窗口内冻结；累计64条真实任务分配后更新一次，允许在同一调度tick内部达到阈值。跨过调度区间不会提前更新或清空缓存。真正回合结束后用剩余全部经验更新，不丢弃、不补齐、不跨回合连接。
- 每轮无放回抽取整个窗口，四组优化器各执行一次。CLI允许1至64条窗口；默认64，不按测试表现选阈值。
- 窗口内部使用实际后继。非终止更新边界仍先按旧任务分布计算候选Critic值和内在奖励的期望，再更新，最后选择真实后继并重算末条历史token。期望候选不充当已执行任务，不额外采样任务来估值。
- RNN按真实顺序重建，每16步使用已保存行为hidden作为截断起点。行为动作概率、行为价值与行为内在奖励保持采集时值；内外层Actor使用同一重新编码的观测快照。
- 外层继续用已观察窗口的样本均值、当前逐样本Jacobian收缩与直接内在奖励偏导，只将估计范围扩展至多个调度区间。不引入额外跨区间时间折扣或长期成本预测；gamma仍在每次决策的一步TD中使用，不改成gamma的5次方。本版不声称等价于旧单区间更新、完整长期梯度或原论文唯一实现。
- 5秒只控制调度tick，物理到达、完成和排队服务事件保留精确时刻。神经网络、历史与训练张量使用float32；公共仿真时间、截止期及能耗积分精度不变。没有AMP、调大学习率或额外损失缩放。

## 工程优化

1. 静态DAG按对象缓存拓扑、父子邻接、特征张量及拓扑层执行索引；合并图批次的静态执行计划也缓存。每回合清理，设备或dtype变化时重建。缓存不存储可复用的训练激活，图网络参数更新后行为嵌入清空并重新计算。
2. 按拓扑层并行执行独立节点，相互独立的工作流也合并执行。仍是前驱均值、特征Softmax、双向两token GRU与方向均值池化；零前驱和填充位置使用零哨兵。
3. 观测、资源张量、掩码、行为log概率、行为价值、内在奖励和历史在设备上保留；环境只接收必要动作编号。窗口标量日志合并回传。CUDA数值诊断在设备上累计全程计数、最大值和最近256行，快照时集中复制，保留原字段、非有限值与梯度检查，不关闭诊断。
4. 资源特征及掩码按环境状态版本复用。每次分配、物理推进、重置均失效；同一时间戳的连续分配也会失效。更新期间状态不变，可以复用边界候选资源与掩码，但更新后的图嵌入必须重算。

## 模型与运行

输出进入 `outputs/{ckpts,run}/irws_r/irws_r_v3_rollout/<配置标识>/model<seed>/`，配置标识含队列、周期、窗口长度、precision。检查点保存这些设置及实现标识；加载时校验，新旧版本互拒，不把旧权重自动转换成新模型。新配置从头训练，同配置仍支持final检查点续训与整套best选择。原有输出覆盖保护保留。

```bash
python launch.py algorithms/irws_r/train.py --task S --resource S --deadline Tight --model-seed 1 --episodes 600 --queue-capacity 10 --slot-duration 5 --rollout-size 64 --precision float32 --device cuda
python launch.py algorithms/irws_r/evaluate.py --task S --resource S --deadline Tight --train-task S --train-resource S --train-deadline Tight --seeds 700-729 --model-seed 1 --queue-capacity 10 --slot-duration 5 --rollout-size 64 --precision float32 --device cuda
```

完整9场景训练及每模型S/M/L组合评测命令见 `Linux_CUDA_IRWS_加速版_训练与组合评测指令.txt`。历史v2指令文件已重定向到 `algorithms/irws_r_v2`，保留1秒与旧模型标识。没有调整并发数、CPU线程设置、验证频率、奖励系数、600回合预算、实例划分、共享归一化或验证最低能耗选模。
