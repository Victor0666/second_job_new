# IRWS 复制后恢复原文机制的实现说明

日期：2026-10-23（Asia/Shanghai）。新增版本位于 `algorithms/irws_restored/`，由此前新版复制后修改。没有修改历史 `algorithms/irws/`、此前新版 `algorithms/irws_paper/`，也没有修改公共场景解析器、资源生成器、执行时间、通信或功耗函数。18个保护文件的源哈希保存在新目录的 `copied_from_sha256.json`。

当前版本为`irws_restored_queue_v2`，按用户确认删除三项新增观测：任务剩余截止期、工作流剩余截止期和Ready等待时间。公共外部奖励、环境截止期和评测仍保留；不称所有公式与作者实现完全等价。原含三项观测的v1模型及验收结果保留，不混作v2结果。

## 已完成的修改

| 项目 | 当前实现 |
|---|---|
| 奖励融合 | 分母非零时严格采用式(30)：`w=t/Rank_dn`、`r=w*r_in+(1-w)*r_ext`；不裁剪大于1的有限权重 |
| 入口边界 | 仅对Rank_dn=0且t>0采用w=1；双零采用w=0，零成本虚拟点不提供有效训练奖励。此为明确的有限边界约定 |
| 等待队列 | 每VM维护运行任务及FIFO等待队列；状态区分Ready、Queued、Running、Finished；忙VM在队列未满时可以接收任务 |
| 状态 | 保留任务计算量、真实等待队列长度、距队尾可用时间、任务预计服务时长、算力、带宽和传输量；删除三项新增截止期/Ready等待上下文 |
| PPO | 概率比只使用VM动作的概率，任务选择概率不进入裁剪损失；删除熵项及其配置 |
| 任务选择 | 式(19)的Q只读取5维图嵌入；Q头固定，不新增独立Q训练损失；图嵌入继续通过元梯度更新 |
| 元梯度 | 删除原副本的一步虚拟SGD及另设外层代理；按式(34)–(39)的两组外层因子和局部近似Jacobian作显式向量收缩 |
| 训练循环 | 每个策略区间先收集调度序列，再随机抽样并逐样本更新Critic、Actor、Intrinsic和Embedding，结束后清理区间记忆 |
| 历史 | 按真实时间顺序重建RNN轨迹，再抽损失样本，不能把随机样本顺序误当历史；删除额外duration/energy token，保留s/a/r/done/s_next |
| 隔离 | 独立模型版本、奖励协议、文件前缀、目录及Checkpoint校验；新旧权重互相拒绝 |

任务选择本身仍需要原式(19)的概率。删除的是其参与VM PPO的联合似然项，不是删除整个任务排序模块。固定Q头并不表示图嵌入固定；Q的输入嵌入仍会变化。本版不声称Q头本身得到了学习。

Q输入由8维缩减为5维。N个VM时，Actor/Critic输入由`9+6N`缩减为`6+6N`；历史RNN的`s/s_next`同步缩减。截止期不再作为显式观测，但RNN仍可通过原有外部奖励接收超期反馈。环境保留deadline及task_subdeadline用于奖励和评测；原文队列长度及预计等待/执行时间保留，它们不同于删除的Ready等待时间。

## 参数对齐口径

按用户确认，公共实验参数与MAHDRL一致，IRWS已明确的学习参数保持原文。27个场景、训练/评测共54组配置已逐项核对：DAX、资源规格、到达率0.03、每回合50工作流、截止期缓存和分布、公共归一化相符；训练600回合，训练种子0–599、验证600、测试700–729。外部延迟权重0.75、能耗权重0.25、能耗缩放0.001、超期分母300秒相同。这些参数已一致，本轮没有为对齐而重写公共配置。

IRWS保留gamma=0.2、batch上限64、四学习率、网络宽度等。MAHDRL没有直接对应的队列容量和策略周期，不强行伪造一致设置。共同参数不意味着奖励归属、调度权限及学习计算量完全相同；此前公平性报告中的其他限制仍成立。

## 公共环境、公平性与最小队列约定

- 共享DAX模板、payload、连续到达轨迹、FCFS参考缓存、工作流截止期、任务子截止期、VM/Host规格、同VM通信减免和主机任务窗口能耗。
- 队列不增加计算/带宽能力；一个VM同一时刻最多执行一个任务，等待本身不记作VM执行负载。不得利用未到达工作流作策略输入。
- 原文没有提供足以唯一复刻的Q_max数值、区间秒长和完整服务顺序。本版固定默认：**每VM最多10个等待任务，不含正在执行者；FIFO、不抢占、不撤销；策略区间1秒**。可通过 `--queue-capacity`、`--slot-duration` 显式指定，输出与Checkpoint绑定这些值。默认值未依据测试性能搜索。
- 排队任务的服务时长由公共固定速率模型确定，因此派发时可以预约确定执行区间；只对这个服务区间写入LoadRecord，不在启动或完成时重复收费。该记账属于预约成本，不能把中间total_energy误称为已实际消耗到当前时刻的能耗；最终结果由公共函数重新积分。
- 物理事件保留精确的到达、启动、完成时刻。区间内完成的任务按真实完成时刻释放后继，策略可以在下个tick再派发；不把Ready时刻或完工时刻取整。
- 同一tick内多次派发不推进物理时间。只有无法继续派发时结束该区间；可以跳过没有调度机会的空区间，期间仍处理全部物理事件。
- 到达轨迹不改成每slot开头批量重新生成，避免破坏公共配对实例；策略按周期观察当前已到达任务。这是公共到达模型适配。

公平性核查覆盖相同实例、物理成本、资源上限、无额外未来信息和每任务一次分配，没有给IRWS增加资源。队列与周期决策是本基线恢复的调度机制，与其他算法既有接口不同，应在实验中披露，不声称所有算法拥有完全相同的决策时机。完整回归还保留九算法的公共配对实例验证。

## 元梯度的可执行解释

论文式(37)/(39)的同名奖励梯度存在自引用；式(36)未清楚区分内在与融合奖励，成本最小化与文字ascent也不一致。按已讨论的最小补全：

1. theta_old是区间采集行为策略；theta是当前样本更新前Actor；theta_prime是当前样本真实Adam更新后的Actor。
2. 收集阶段计算并保存内在奖励和一步TD所需旧值。PPO优势按采集轨迹冻结，Actor/Critic按式(22)/(24)/(31)训练，不增加熵。
3. 从整个已观察区间计算两组后更新策略score梯度。每样本保留式(35)/(38)的 `gate * ratio * advantage`；成本组再乘对应样本的共同外层成本。gate为原式的裁剪生效条件。对区间内样本求和，保留节点求和语义。
4. 用更新前VM score与两组外层梯度收缩，分别乘式(36)/(39)的 `alpha_in*w`、`alpha_WE*w`，再乘预更新内在奖励对phi/eta的直接偏导。显式使用r_in的偏导以避免再次把融合权重乘入，防止w重复计数。
5. phi沿共同成本下降，eta沿奖励方向上升。实际四优化器仍为Adam。论文近似Jacobian中的alpha_in/alpha_WE与优化器自身步长分别保留，未人为放大。
6. 只用已观察区间估计期望/未来和，未观察未来项截断。一个区间中的样本时间索引相同，因此该区间内gamma^(i-t)=1；PPO一步TD仍使用gamma=0.2。本版不构造额外的未来成本Critic或虚构反馈。

以上是依原文因子构造的有限样本近似，不是完整Adam历史的精确二阶导数，也不能声称解决了原文所有记号歧义。两个外层score梯度均通过固定系数下的方向有限差分检查；局部Jacobian收缩另有独立数值因子检查。

## Algorithm 1 与历史处理

- 一个策略区间内网络不更新，收集Ready任务的派发序列。
- 区间结束后随机无放回抽取 `min(64,记忆条数)` 个样本，按抽样顺序逐样本执行四优化器更新，默认S=1。论文没有说明记忆少于64时如何抽样；这里不复制经验凑够64条。
- RNN采用论文轨迹长度16重建有真实上下文的连续前缀；梯度不跨前缀起点。抽样打乱只影响损失更新顺序，不影响RNN历史顺序。
- 真实后继任务在边界先固定以提供更新前Critic尾值；区间更新后刷新该已选任务的图编码再执行其VM动作。下一VM动作由更新后的Actor产生，不伪造旧log-prob。
- 所有已经到达任务最终排空后结束，完成时刻保持真实值。正式交互预算仍为每episode 50个工作流、默认600episode，没有增加工作流样本。

## 暂未改动的内容

- 公共外部奖励及外层目标仍是能耗—任务超期，未改回原论文makespan—energy。
- 图聚合轴、Bi-GRU序列、池化方式沿用复制源的工程解释，未借本次任务增加新结构。
- 主要网络宽度、学习率、gamma、轨迹长度、共享归一化、实验划分及按验证能耗选模不变。

## 输出和使用

模型版本为 `irws_restored_queue_v2`；奖励协议为 `common_energy_tardiness_paper_fusion_v1`。

- 模型：`outputs/ckpts/irws_restored_queue_v2/<源场景_协议_尺度_q10_dt1>/best.pth` 与 `final.pth`。
- 训练日志：同目录的 `train_irws_restored_taskS_resS_Tight_model1.jsonl`，测量记录位于logs。
- 评测：`outputs/run/irws_restored_queue_v2/<同源标识>/<目标场景>/` 下独立CSV、JSON及逐种子测量。
- 改变队列容量或区间秒长会进入不同子目录，加载时也核对这些设置。包括含三项观测的v1在内，旧权重不能迁移为本版本结果，须重新训练。模型版本校验会明确拒绝旧输入维度。

入口和PowerShell/Linux命令见 `algorithms/irws_restored/README.md`。正式运行继续严格检查公共新版Deadline Cache和共享归一化配置；本轮未启动正式600回合训练或30种子正式性能比较。
