## 2. 与论文仍然不同或不能认定等价的地方

### 2.1 外部奖励及外层目标已经替换

原文 p.904 式(20)使用相对平均服务器的 EFT/能耗改善；p.905 式(25)–(27)是工作流完成时间与能耗的长期目标，并有任务数、区间平均。当前实际为：

`r_ext = -0.25*0.001*delta_energy - 0.75*clip(task_tardiness/300,0,1)`

`outer_cost = -r_ext`。

这适配了当前能耗—超期问题的方向，但属于目标替换，不是仅修改 alpha 参数。原式(28)的规范化完工差/能耗改善也未保留为 RNN 的显式定义性目标。论文没有明确要求对式(28)做监督 MSE，因此不能单以“没有该 MSE”判错。

依据：[外部奖励](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/environment.py:215>)；[公共任务超期定义](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/environments/irws.py:744>)。

### 2.2 截止期输入仍然保留，尚未成为“只输入图嵌入”

图编码器的原始输入是两个 rank，但任务 Q 仍读取“5维嵌入 + 任务子截止期剩余 + 工作流截止期剩余 + Ready 等待”。VM Actor/Critic 的资源状态也保留这三项，RNN 通过状态继续读取它们。

原文式(19)为 `Q(e_v_DAG)`，没有这三项输入。这是尚待决定的第7项，不是已删除。本轮不替用户决定删除。MAHDRL 自己也读取任务截止期、slack、等待等，因此 IRWS 使用截止期信息本身不构成独占未来信息。

依据：[Q输入](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/networks.py:76>)；[上下文及资源状态](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/environment.py:165>)；[MAHDRL截止期排序属性](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/environments/mahdrl_heft.py:1087>)。

### 2.3 Q头冻结是补全选择，不是论文明确规定

当前 Q 是随机初始化后冻结的非线性打分器。图嵌入仍可改变，因此任务排序并非永远固定，但 Q 头没有得到独立学习。原文给了 Q/Softmax 选择，却没写完整的 Q 优化机制；“没有写学习规则”不能直接推出“作者就是固定随机 Q”。

这是依此前“不另造 Q 损失”的要求采取的可运行补全，应明确标注。它可能削弱任务排序，不能用该版本的结果代表作者原始 Q 训练效果。删除的是联合 PPO 似然，任务 Softmax 本身仍存在，以保留原式(19)。

依据：[冻结Q](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/networks.py:62>)。

### 2.4 元梯度是按原文因子构造的近似，尚非长期目标的等价实现

当前 `_outer_scores` 仅对本区间缓存求和，`outer_cost` 为当次已分配任务的成本；区间更新后清空。原文式(35)含跨未来区间的折扣和，并不是只有当前区间。已预约任务的预计完工成本包含其排队影响，但不包含当前动作对后续新到工作流及后续决策的所有影响。

还有三项不能略过的解释：

- 当前使用内在奖励的直接偏导来解释原文中含糊/自引用的奖励梯度，并人为区分 phi 成本下降与 eta 奖励上升。原文记号和“成本最小化/ascent”文字存在矛盾，当前解释不能说成作者唯一实现。
- `_outer_scores` 在 Actor 真正更新之后计算 ratio/gate；原式(35)/(38)的因子仍写 `xi(theta)`，同时 score 写更新策略。按当前代码区分 theta 与 theta_prime 的约定，不能声称每一项均逐字一致。
- `_sample` 会用当前 eta 重新编码，而 `_outer_scores` 使用采集时存下的编码。一次区间中经过先前样本的 eta 更新后，内外两支不再使用相同编码。这又是一层实现近似。

不对 Adam 全历史做精确二阶求导本身并非判错依据：原文给出的也是近似梯度。但删除未观察未来项和采用这些编码/偏导约定，是需要披露的算法估计选择，不能全部归为“原文没写，所以可无影响删除”。

依据：[重建当前编码](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/learner.py:121>)；[外层score](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/learner.py:148>)；[区间更新及梯度](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/learner.py:165>)。

### 2.5 区间边界和图网络细节仍含工程解释

边界下一任务在更新前先选好，更新后仅刷新该任务编码。原文 Algorithm 1 第5行是在新区间用嵌入生成调度顺序。当前做法保障旧 Critic 的真实后继取值，但并非字面相同的排序时序。

图聚合的 Softmax 轴、两 token Bi-GRU、双向均值池化等仍沿用复制源的解释，论文细节不足以唯一确定这些结构。尤其当前：

`softmax(Wself(h_v)+Wneighbor(states),dim=0)`

对邻居维做 Softmax，`Wself(h_v)` 对每个邻居相同，因 Softmax 平移不变性被抵消。数值复核中其梯度最大绝对值约 `1.00e-17`；大幅改变该权重后输出差约 `1.57e-15`。该分支实际无效。自身状态仍经过 GRU，所以不能说整个网络丢失自身信息。

这是复制源已存在的问题，不是新队列修改引入。应重新核对式(16)的可执行聚合定义，不能把当前含无效分支的解释当作已确定的论文机制。

依据：[边界顺序](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/runner.py:77>)；[聚合公式](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/networks.py:25>)。

## 3. 对当前问题的适配风险

### 3.1 原式融合可使外部惩罚的直接系数变号

`w>1` 时 `1-w<0`。固定内在奖励为0、w=2：外部奖励从-1降为-2，融合奖励从1升为2。即更大的能耗/超期惩罚，在这一直接奖励项中反而成为正向激励。

既有真实 DAX 短程记录中，54次分配有8次 w>1，最大约2.968；另有26次零rank边界取 w=1，使直接外部项为0。这些记录是可运行短程，不是正式性能实验；数值足以证明情况会发生，不足以证明最终策略必然更差。

外层仍读取公共成本，RNN输入也包含外部奖励，因此不能推断整个算法完全忽略能耗或超期。不过，不能假定元学习一定抵消变号效果。保留原式是此前明确选择，属于“公式忠实性与新负惩罚目标之间的张力”，不是抄错了式(30)。若改变权重范围/融合方式，应另列适配版或消融，不能再称原式未变。

依据：[权重边界](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/environment.py:34>)；[融合函数](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/learner.py:22>)；[既有短程记录](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/docs/IRWS_restored_smoke.json>)。

### 3.2 截止期目前是软惩罚，选模也没有截止期门槛

超过任务子截止期300秒之后，当前即时超期项均为-1；再晚的任务不在此项中进一步区分。工作流级截止期主要用于观测和评测，而非硬约束。

IRWS与MAHDRL目前都按验证总能耗最低保存最佳模型。即便某模型能耗下降、截止期成功率恶化，仍可被选为best。若当前研究问题要求“在达到某截止期成功率要求下最小化能耗”，这套选模标准尚不匹配；若研究的是能耗—超期软权衡，也应明确选模指标为何只选能耗。

这属于双方共同的实验设计问题，不是 IRWS 单独占便宜。若调整，应对所有方法统一调整，并且只能使用验证集。

依据：[IRWS选模](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/runner.py:199>)；[MAHDRL选模](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/mahdrl/train.py:463>)。

## 4. 与 MAHDRL 相比，哪些相同，哪些不对称

### 4.1 已有共同基础

同一场景下采用相同 DAX/payload 生成、到达实例、资源档位、FCFS参考deadline缓存及分布、执行时间与通信规则、Host任务窗口功耗核算；固定训练/验证/测试划分。默认都是每episode50个工作流、600训练episode，实例训练种子0–599、验证600、测试700–729。

排队不增加 CPU/带宽资源，一个VM同一时刻只执行一个任务；预约未来已确定任务的服务时间不等于偷看未到达工作流。当前未发现为 IRWS 额外提供未来到达轨迹作为策略输入、降低能耗单价或放松截止期。

已有短程核查：54次分配、47次真实排队，执行时长最大误差约1.14e-13，最终能耗再积分误差0，依赖与VM无重叠成立。本轮还重跑当前10项专项测试，全部通过。测试证明这些实现性质，不证明学习效果或原文数值等价。

### 4.2 决策权限不同，不能称完全相同的控制条件

| 情况 | IRWS restored | MAHDRL |
|---|---|---|
| VM忙且队列未满 | 可派入FIFO队列 | 非法，动作mask过滤 |
| 当前存在空闲慢VM和忙碌快VM | 可选择在快VM等待 | 只能选择当前空闲VM |
| 到达/完成在非整数秒 | 事件按准确时间处理，策略等待下一tick | 事件时刻可形成决策点 |
| 已提前分配任务 | 不可撤销，后到任务不能插队 | 未分配的Ready任务可在之后阶段重新排序 |

本轮直接复核：同一物理状态下，VM0尚需10秒，另外两VM空闲；IRWS mask为 `[1,1,1]`，MAHDRL为空闲mask `[0,1,1]`。

因此，排队提供提前绑定的能力；FIFO锁定和周期观察也可能伤害 IRWS。单凭源码不能判定净优势方向。队列是原文原生机制，不应为了“统一接口”直接删掉后再声称忠实原文。

可以将这种结果称为“同一物理场景下、保留原生调度机制的系统级比较”，但不应称为“同一个MDP、相同动作权限下仅比较学习算法”。若要分离接口影响，需另做共同控制条件下的适配消融，并将其与保留原生队列的版本区分。

依据：[IRWS队列mask](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/algorithms/irws_restored/environment.py:73>)；[MAHDRL拒绝忙VM](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/environments/mahdrl_heft.py:579>)；[MAHDRL事件推进](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/environments/mahdrl_heft.py:981>)。

### 4.3 “相同奖励权重”不等于相同学习奖励

IRWS在派发时收取预约服务区间带来的能耗增量，并使用预计完工超期；MAHDRL下层在时间推进时结算全局/所选Host区间能耗，阶段尾还会补入pending决策。MAHDRL TA使用阶段内新完成任务的未截断超期总和/300；IRWS外部超期项逐任务clip。

这使相同物理日程的训练反馈时点、归属和局部惩罚不同。它们可以是原生算法/层级奖励设计差异，不能据此自动判不公平；但也不能因同为0.75/0.25就声称两者优化的是完全同一个逐步目标。公平的最终比较应使用统一的物理能耗、工作流成功率、任务/工作流超期等，不能比较两种算法的内部累计reward大小。

依据：[MAHDRL下层奖励](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/environments/mahdrl_heft.py:609>)；[TA奖励](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/environments/mahdrl_fcfs.py:199>)；[尾部结算](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/common/f11.py:193>)。

### 4.4 同episode只统一了交互预算，未统一计算预算

IRWS每区间随机抽取min(64,n)个样本、逐样本四组Adam更新；MAHDRL使用经验回放、预热、256批量及各层更新。默认保留原文gamma=.2，而MAHDRL为.95。这些差异不能自动判为偏袒，也不应为了“公平”把各方法全部改成MAHDRL参数。

论文应披露实际优化器步数、样本呈现次数、网络规模和训练时间。否则只能声称相同工作流样本预算，不能声称相同训练计算量。固定随机Q、失效的图权重分支、短外层估计还可能削弱IRWS；公平性也包括不把弱化的复现当成作者算法最佳表现。

共同单验证实例、单训练初始化种子的限制亦需说明；30个测试实例种子不等于30次独立训练。

### 4.5 评测字段不得混用

IRWS遗留 `wf_avg_tardy` 是“按工作流平均的任务超期和”，而 `wf_avg_tardiness` 才是“平均工作流完工超期”。MAHDRL的 `wf_avg_tardiness` 对应后者。当前存在正确字段，并不表示已经发生错误比较；后续汇总不能把这两个近似名称视为同指标。

依据：[两个字段的计算](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/environments/irws.py:986>)；公共测量的 [workflow指标](<E:/读博生活/0.科研/1.论文/2. 第二个任务/1. 论文实验材料/second_job_new/common/experiment_measurements.py:60>)。

## 6. 建议的处理优先级及可使用的结论

1. 正式比较前，优先核实图聚合无效分支与元梯度估计，准确标注固定Q及长期目标截断；这些直接关系到是否弱化IRWS。
2. 原式融合保持为忠实性版本时，披露w>1及入口边界的统计；若修改其数学形式，应另命名适配版，不覆盖忠实性版本。
3. 明确比较的是保留原生调度机制的系统级方法，还是共同动作权限下的学习算法；必要时增加接口消融，保留原生队列版本。
4. 若研究目标含截止期达标要求，统一各算法的验证选模规则和最终指标；不单独调整IRWS或MAHDRL，也不用测试集选规则。

适合当前证据的表述是：**“在共同实例和物理模型下，实现了保留多项原文机制的 IRWS 问题适配版；原文未充分指定处使用显式工程约定。其长期梯度、观测和控制接口仍有差异，不能声称与作者实现完全等价或已排除所有比较偏差。”**

本轮未运行正式600episode训练、30种子正式性能比较或新消融，不能量化上述差异的净性能方向。专项测试通过与数学因子有限差分通过，仅验证当前实现的若干性质，不验证该实现等价于原文的全部目标。
