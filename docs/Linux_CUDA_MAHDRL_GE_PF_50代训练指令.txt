# Linux / Bash：MAHDRL-GE、MAHDRL-PF 各九场景，训练 50 代
# 从项目根目录、已激活的 Python/CUDA 环境执行；每组为可单独复制的后台命令。
# 固定训练 task=S，resource=S/M/L × deadline=Tight/Medium/Loose；模型种子=1，F22，F19。
# 显式检查 CUDA；不可用时停止该组，不自动回落 CPU。
# 注意：50 与 600 代使用同一算法/场景的模型及训练日志目录，不支持续训，也不允许覆盖非空训练目录。
# 若先跑50代，先评测并归档该变式的模型、训练日志和评测结果，再从头跑600代。
# ep50 仅区分这里的控制台 .log/.pid，不会自动隔离模型目录。
# GE 与 PF 的模型/日志/结果彼此隔离；这些清单没有建立组合版本。
