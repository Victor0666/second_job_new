# Linux / Bash：PD3QN-FE 九个源模型训练与27场景评测

# 同一源模型的三个目标结果分别保存在taskS/taskM/taskL目录；控制台日志合并在该源模型的SML日志中。
# 若原S目标已完成，将对应for task in S M L改为for task in M L，只补两个泛化目标。
# 逐段复制所需场景，不要直接运行整个清单；根据GPU显存和CPU资源安排并发。
# CUDA_VISIBLE_DEVICES=0表示物理GPU0；按服务器实际分配调整。--device cuda不可用时会退出。
# 先完成对应场景训练，再执行其评测。模型、训练日志及评测结果与其他算法隔离。
