# R03 新版 IRWS 共同问题适配

本轮按公共能耗与任务超期目标适配新版 IRWS，保留 DAG 嵌入、任务选择、PPO、历史 GRU 和元梯度。它是 IRWS 的公共云问题适配版本，不再声称奖励逐式复现原文。旧的简化 IRWS 未删除，也未变更其训练逻辑。

## 本次发现并修正的问题

| 问题 | 调整 |
| --- | --- |
| 包装层丢弃公共奖励，换成伪平均服务器相对改善 | 直接使用一次 super().step 的实际奖励，无重复执行或二次能耗计量 |
| 元学习仍优化完成时间与能耗，并除当前工作流任务数 | outer_cost = -external_reward，使用共同全局能耗与超期成本，不另作工作流大小加权 |
| 原融合比例可能大于 1，外部奖励被反向或在入口变零 | 动态权重为 t/(t+Rank_dn)，零零取0；训练奖励为 external + weight × intrinsic，外部系数始终为1 |
| 任务打分与VM状态没有直接的截止期信息 | 任务打分拼接当前任务子截止期剩余、工作流截止期剩余和Ready等待时间；VM观测也包含这三项 |
| 图嵌入缓存会使直接塞入图的动态特征过时 | 图嵌入继续缓存静态拓扑；截止期上下文每次真实决策重新计算，并随行为决策保存供更新重算 |
| 原模型与新目标可能混用 | 独立模型版本、奖励协议和系数检查；旧目标模型拒绝加载，必须重训 |

共同外部奖励严格复用底层环境：

`r_ext = 0.25 × (-0.001 × delta_energy_total) + 0.75 × r_delay`

`r_delay = -clip(max(0, finish - task_subdeadline) / 300, 0, 1)`。

它与当前 PD3QN 和旧 IRWS 使用的全局资源分配基础奖励口径一致；MAHDRL 的 HA 也采用全局能耗与任务超期项，而其 TA 按phase结算、VA按所选host局部能耗结算。因此不能说所有层的每一步奖励数值完全相同。

全局能耗由公共环境一次结算，覆盖全部主机与最终尾部空闲窗口；没有重新引入所选host边际能耗作为外部目标。原伪平均服务器成本、完成时间目标、原式28诊断和对应历史状态已从当前奖励路径移除。

## 内在奖励的定位

内在奖励保持可学习，通过实际共同成本的元梯度优化。新增方式是明确的问题适配：`r_train = r_ext + lambda × r_int`，不是原式30的凸组合，也不是固定0.1混合。`lambda = t / (t + Rank_dn)` 在[0,1]内，入口为1时仍完整保留外部奖励；两个时间均零时为0。

PPO与外层仍采用既有算法折扣及有限rollout代理，不能宣称等价求解未折扣episode总能耗或严格保证概率QoS约束。内在奖励为算法专有学习机制，不要求不同算法的融合后训练奖励数值相同。

## 观测与模型隔离

任务打分输入为5维图嵌入加3维动态上下文。VM策略输入为5维图嵌入、工作量、3维上下文和每VM的6维属性，即 `9 + 6N` 维。三项上下文均按源训练场景共享 T_ref 缩放，允许负剩余时间，不读未来工作流；非约束测试环境不使用巨大horizon占位截止期作为特征。

新目录版本：`irws_cloud_energy_tardiness_v2`。奖励协议：`common_energy_tardiness_additive_intrinsic_v2`。Checkpoint 保存版本、共同奖励系数、网络和优化器、RNG及公共协议和归一化指纹，加载时检查目标。不能继续用 `irws_paper_cloud_v1` 的权重作为新版本结果。

## 保留的共同条件和算法差异

共同DAX、payload、到达、alpha、任务子截止期、VM/host规格、通信、物理能耗窗口、默认训练验证测试划分、600回合预算和按验证能耗选模均沿用原公共协议。没有扩大Ready候选权限、增加交互预算或依据测试结果调参。

网络宽度、PPO、图嵌入、元梯度近似、float64、学习率和现有 gamma=0.2 等算法配置本次保留；它们是需披露的算法差异，不应机械统一。不同更新预算、单验证种子以及共同能耗选模未检查QoS的限制仍存在，不能仅凭本次外部目标统一宣称全部公平性问题已消除。

原 TL/TL_2 的场景测试适配到共享runner，IRWS公共协议穿透测试使用显式环境注入；仅补齐测试接线，不改变其他算法的调度策略。
