## 已确认的共同环境边界

继续使用 `IRWSEnvRouteA` 和现有 F07/F02 公共模型：随机工作量、完整父输出文件、同 VM 通信减免、全部主机共同窗口积分、配对模板/到达/alpha/Deadline 不在本次重定义。完整图应由 `env.workflows` 中已经到达的图构造；节点必须以 `(workflow_id, local_task_id)` 映射至全局任务编号，禁止读取未来工作流缓存记录作为策略输入。

现有任务特征包含计算、输入、输出、上下秩、slack、等待；VM 特征包含空闲、可用延迟、计算能力、带宽、预测执行时间和 slack。后续可在算法状态拼接结构嵌入，不应在 IRWS 内复制另一套文件或能耗模型。

当前 `get_vm_obs_and_mask()` 在无空闲 VM 时把最后一个 VM 强制标为合法，这一回退不符合统一资源约束。正常环境推进后应当已有合法 VM；完整适配时应在异常状态明确报错，而非伪造合法动作，并增加测试。目前仅记录，不在缺少完整方案时提前混入局部修复。

## F14 现有实现的确认

- 正常终止：末端价值为零，GAE 由 done 截断。
- 2048 条经验的非终止边界：先由现有任务选择器选定下一任务，获取该任务的 VM 状态，用更新前参数估计 `last_value`，然后更新 PPO。
- 非终止批次未提供 tail value：明确报错，不清空缓冲区。
- 单条经验尾部不再直接丢弃；无法取得后续状态的截断采用明确 cutoff。
- F11 专项数值测试已验证非终止目标 -11 与终止 -2，以及跨 Episode 的 GAE 截断。

但图网络、任务选择策略参与更新后，下一任务的采样参数版本与 PPO 尾值版本也必须保持一致。现有 F14 测试通过不代表尚未实现的联合学习路径已验收。

## 训练协议的额外冲突

当前八种学习算法从 seed=1 开始按 Episode 递增，默认 600 回合；验证均使用 seed=1；默认最终测试为 seed=2–31。因此训练、验证、测试实例种子存在交叉。这与本次“严格分离”的要求冲突。

只给 IRWS 换种子会破坏共同实验协议；修改所有算法又超出仅 IRWS 算法修复，并影响现有 F06/F11 配置约定。正式实施时需明确统一的 train/validation/test 划分，同时保留训练预算和按验证能耗选择最优模型的规则。不可把当前协议描述为已经无泄漏。

现有选模只比较验证总能耗，未用 Deadline/能耗联合分数。本次任务明确要求不擅自更改，应保留并在实验设置披露。长期元目标的能耗归一化需要事先固定、与共同尺度一致，不能依据最终测试结果调参。

## 待原文核验后的实现路径

1. 双向拓扑 DAG 编码，父/子邻居可训练聚合和门控更新，输出固定维度任务及图嵌入；以两个拓扑不同但属性相同的图验证结构依赖。
2. 任务过滤策略使用完整图编码的 Ready 子集；保存任务 log-prob、VM 条件 log-prob。必须推导两者联合策略概率或分开的相容更新方式，不能重复计数策略梯度。
3. PPO 输入拼接已选任务的图嵌入；仍直接选择合法 VM，维度变化以新版本 Checkpoint 隔离。
4. 按工作流身份维护历史 GRU，输入只含当时已经发生的动作/奖励/反馈，同时保留集群竞争状态。Episode reset 清空隐藏状态。
5. 核查参考执行时间与 Rank_dn 定义、单位和同 VM 未知时的估计规则；按原式计算融合，异常保护逐项记录，不静默反转权重。
6. 明确可微内层优化与长期调度成本的策略梯度估计，推导外层参数依赖、估计样本来源和梯度方向。允许任务要求认可的截断展开近似，但必须通过可手算/有限差分测试验证；不能拿普通奖励回归替代元梯度。
7. GNN、任务过滤、VM 策略与 RNN 的优化器、更新顺序、样本政策版本、梯度隔离和 Checkpoint 状态必须统一设计；F14 与该政策版本严格绑定。
8. 全部模块和优化器、RNG、配置、进度、最佳验证指标保存恢复；只有新适配版 Checkpoint 才能进入正式评测。评测确定性、无训练、无内在奖励污染物理指标。
9. 完成 T01–T22、15 模板兼容、短程联合训练、w/o-IR 与 w/o-WE 诊断后才标记可正式重训。

上述是待核验路径，不是已经完成或得到原文确认的算法。
