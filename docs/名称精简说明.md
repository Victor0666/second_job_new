# 文件与输出目录命名（2026-10-16）



算法由父目录区分，文件名保留用途、工作流规模、资源规模和截止期等级。taskS/taskM/taskL 表示小/中/大工作流规模，resS/resM/resL 表示小/中/大资源规模。Tight/Medium/Loose 保留原义。seed、奖励权重、混合截止期及消融标记在需要区分的模型目录中保留；具体训练参数仍以脚本内容为准。



| 用途 | 当前示例 |

|---|---|

| 主算法训练 | `b_mahdrl/train_taskS_resS_Tight.py` |

| 主算法评测 | `c_run/mahdrl/eval_taskS_resS_Tight.py` |

| 主算法环境 | `b_mahdrl/env_fcfs.py`、`env_heft.py` |

| 截止期预计算 | `a_deadlines/precompute_ddl_fcfs_ss.py` |

| 截止期缓存 | `d_output/deadlines/ddl_fcfs_taskS_resS_seed0-1000.json` |

| 主算法模型 | `d_output/ckpts/mahdrl_taskS_resS_seed1_r075_ddlMix_hv_Tight/` |

| 训练日志 | `d_output/logs/mahdrl_taskS_resS_seed1_r075_ddlMix_hv_Tight/train.csv` |



r075 表示原 rAlpha075；ddlMix 表示原混合截止期配置；hv 保留原 HVrn 配置含义；hostrand/vmrand/mgrrand/nohost 区分消融。历史结果中的其他权重、截止期系数、seed 和迭代次数仍保留，不合并实验结果。



推荐入口：



```powershell

.\run.cmd b_mahdrl/train_taskS_resS_Tight.py

.\run.cmd c_run/mahdrl/eval_taskS_resS_Tight.py

.\run.cmd verify_package.py --imports-only

```



同步范围包括 Python 导入、模块动态加载、模型路径、训练日志路径、评测 CSV 路径、截止期缓存通配符、模型候选目录过滤条件和绘图脚本中的相关路径。extraction_manifest.json 使用当前路径，source_path 和原始提取哈希仍用于溯源。旧审计/验证资料、CSV/JSONL 实验内容与模型权重保留原样；历史报告中的旧路径仅是历史记录。



完整原名到最终名称的对应见 name_shortening_validation.json 的 mapping。两次处理前的文本备份分别在 name_shortening_backup.zip 和 name_shortening_stage2_backup.zip；ZIP 内 mapping.json 为当次路径映射。目录移动前后逐文件 SHA-256 比较已通过（有意修改的代码、说明和清单除外），未删除或覆盖实验文件。
